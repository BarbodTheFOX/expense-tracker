# Expense Tracker

A simple desktop expense tracker built with Python and CustomTkinter.

## Features

- Add expenses
- Show all saved expenses
- Delete the last expense
- Save and load data with JSON
- Category dropdown
- Currency dropdown
- Separate totals for USD and IRR
- Compatibility with older saved JSON data

## Built With

- Python
- CustomTkinter
- JSON

## Current Categories

- Food
- Travel
- Shopping
- Bills
- Health
- Other

## Current Currencies

- USD
- IRR

## How It Works

Each expense includes:

- title
- amount
- category
- currency

The app stores expenses in a local `expenses.json` file and loads them automatically when the app starts.

## Project Status

This project is currently a beginner desktop app built for learning Python GUI development, app logic, and file handling.
